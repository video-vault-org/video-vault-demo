# Demo project instructions

- This is the public, read-only static demo copied from VideoVault's frontend. It has no backend, database, credentials or private runtime configuration.
- Bundle only public example content. Never add real installation data, secrets, login tokens or private media.
- Keep write operations disabled, including comment, account, user and video changes. Do not add API calls or an authentication requirement.
- Keep German and English text consistent and clearly identify public demonstration data.
- Use anonymous function expressions assigned to const. Collect named exports at the end of each module; put default exports after their declarations.
- Leave blank lines between functions and after imports. Place interfaces/types after imports and before runtime code.
- Do not modify the original webapp or its security architecture for demo-only changes.
